# 출고비서

출고비서는 여러 채널로 들어오는 주문 정보를 직접 입력 없이 수집하고 분석해 출고표로 자동 정리하는 출고 업무 자동화 플랫폼입니다.

소규모 유통업자와 현장 중심 사업자는 주문을 한 곳에서 받지 않습니다. 전화, 통화녹음, 문자, 카카오톡, 이메일, 메모처럼 여러 채널에 주문 정보가 흩어지고, 결국 사람이 다시 듣고 읽고 옮겨 적어 출고표를 만들어야 합니다. 출고비서는 이 반복 작업을 줄이는 것을 목표로 합니다.

영문명과 개발명은 ShipMate를 사용합니다.

## 해결하려는 문제

많은 소규모 사업장은 별도의 주문 시스템보다 휴대폰과 메신저에 의존합니다.

- 전화로 주문을 받고 나중에 통화녹음을 다시 확인합니다.
- 카카오톡과 문자에 품목, 수량, 주소가 흩어져 있습니다.
- 이메일 주문서와 구두 주문이 함께 들어옵니다.
- 출고 전에는 모든 주문 정보를 사람이 다시 정리해야 합니다.
- 누락, 오기입, 중복 확인에 시간이 많이 듭니다.

출고비서는 흩어진 주문 정보를 한데 모아 구조화하고, 출고 업무에 바로 사용할 수 있는 형태로 바꾸는 것을 지향합니다.

## 제품 목표

출고비서의 목표는 단순한 파일 업로드 앱이나 관리자 도구가 아닙니다.

궁극적으로는 다음 흐름을 자동화합니다.

```text
여러 채널의 주문 정보
-> 주문 정보 분석
-> 주문 후보 정리
-> 사용자 확인
-> 출고표 자동 생성
```

사용자는 주문 내용을 일일이 다시 입력하지 않고, 정리된 결과를 확인하고 수정하는 방식으로 업무를 처리할 수 있습니다.

## 주요 입력 채널

출고비서는 장기적으로 다음과 같은 입력을 다룹니다.

- 카카오톡 메시지
- 문자 메시지
- 이메일 주문
- 가맹점 또는 거래처 전용 주문 페이지
- 수기 메모 또는 직접 입력
- 휴대폰 통화녹음
- 유선전화 또는 인터넷전화 녹음

통화녹음 자동 업로드와 업로드 검증 흐름은 기존 구현 기반으로 유지하되, 신규 주문 채널 개발 우선순위에서는 전화/통화녹음 주문을 가장 마지막으로 둡니다.

## 주문 채널 개발 우선순위

출고비서는 고객이 이미 쓰는 주문 방식을 유지하면서, 출고비서 이용자에게는 검수 가능한 주문 초안과 출고표로 제출하는 것을 목표로 합니다.

1. 카카오톡 주문요청
2. 휴대폰 문자 주문요청
3. 이메일 주문요청
4. 가맹점 또는 거래처 전용 주문 페이지
5. 기타 채널
6. 전화 및 통화녹음 주문

## 주요 기능 방향

출고비서는 입력 채널을 하나로 제한하지 않고, 실제 현장에서 주문이 들어오는 방식을 출고표 생성 흐름으로 연결합니다.

- 카카오톡 공유 기반 주문 수집: 고객이 보낸 카카오톡 주문 내용을 이용자가 출고비서로 공유하면, 주문 원문을 저장하고 주문 초안으로 전환합니다.
- 문자 공유 기반 출고표 생성: 이용자가 휴대폰 문자 앱에서 발주 문자를 출고비서 Android 앱으로 공유하면, API가 문자 원문을 저장하고 주문 초안을 생성합니다.
- 이메일 발주 수집: 이용자별 전용 발주 이메일 주소를 발급하고, 해당 주소로 들어온 이메일을 주문 초안과 출고표로 전환합니다.
- 이용자별 브랜드 주문 채널: 고객에게는 출고비서 공통 채널이 아니라 `(주)한국유통 주문 접수`처럼 거래처 자체 채널에 주문하는 느낌을 주는 화면을 제공합니다.
- 가맹점 검수 화면: `shipmate-merchant`에서 이메일, 문자, 웹 주문 등으로 생성된 주문 초안을 확인하고 수정한 뒤 출고표 생성을 승인합니다.
- 통화녹음 자동 업로드: Android 앱이 통화 종료 후 생성된 녹음 파일을 서버로 업로드하고, 서버는 이후 주문 분석과 검수의 원본 자료로 보관합니다. 주문 채널 개발 순서에서는 가장 마지막에 둡니다.

## AI 활용

출고비서는 주문 정보를 분석하고 구조화하기 위해 AI를 내부 기술로 활용합니다.

AI는 통화녹음, 메시지, 카카오톡, 이메일 등 여러 채널의 주문 내용에서 품목, 수량, 거래처, 배송지처럼 출고표 작성에 필요한 정보를 추출합니다. 이후 사용자가 확인할 수 있는 주문 후보를 만들고, 최종적으로 출고표 자동 생성으로 이어지는 기반을 제공합니다.

AI는 제품 이름이 아니라 출고비서 안에서 반복 입력과 정리 업무를 줄이기 위한 분석 기술로 사용됩니다.

## 핵심 가치

출고비서가 제공하려는 가치는 명확합니다.

- 주문 정보를 다시 입력하는 시간을 줄입니다.
- 전화와 메시지에 흩어진 주문을 한 곳으로 모읍니다.
- 출고표 작성 전 누락과 중복을 줄입니다.
- 소규모 사업자가 복잡한 ERP 없이도 주문 정리 자동화를 시작할 수 있게 합니다.
- 현장에서 이미 쓰는 휴대폰 중심 업무 흐름을 유지합니다.

## 현재 개발 단계

현재 주문 채널 MVP는 카카오톡 공유 주문과 문자 공유 주문을 우선합니다.

사용자가 카카오톡이나 문자 앱에서 주문 내용을 출고비서로 공유하면 Android 앱은 주문 원문을 확인 화면에 표시하고, API는 원문을 저장한 뒤 주문 초안과 출고표 생성 흐름으로 연결합니다.

`shipmate-merchant`는 포장재 주문제작을 첫 기준 업종으로 두고, 로그인, 권한별 처리, 주문 원문 접수, 주문 원문 목록, AI/규칙 기반 품목 후보 추출, 포장재/판촉물/맞춤 제작 필드 검수, 고객/단가표 관리와 보관 처리, 배송 정보 검수, 출고표 제출과 취소, 제출된 출고표 조회, 택배사별 CSV 검증과 다운로드, 출고표/작업지시서/납품서 인쇄, 기간별 운영 대시보드, 이메일 수집 설정과 메일 서버 연결 확인, 변경 이력/오류 로그, 백업 확인과 복구 승인 화면을 제공합니다.

`shipmate-admin`은 출고비서 운영자와 사원이 접속하는 내부관리자 화면으로, 내부 계정 로그인, 운영 대시보드, 이용자/가맹점 관리, 직원 계정 생성, 주문 원문/출고표 초안/제출 출고표 조회, 통화 녹음 관리, 오류 로그, 변경 이력, 백업 미리보기, 시스템 설정 조회를 제공합니다.

전화 및 통화녹음 주문은 현장성이 있지만 권한, 음성 인식, 개인정보, 검수 부담이 크므로 주문 채널 개발 순서에서는 가장 마지막 단계로 둡니다.

## 개발 및 검증 방식

출고비서는 AI-assisted development 방식으로 개발되고 있습니다.

기획 정리, 코드 작성, 문서화, 테스트 흐름 점검 과정에서 AI 개발 도구를 활용합니다. AI가 생성하거나 수정한 내용은 사람이 검토하며, 실제 제품 방향과 기능 판단은 현장 업무 흐름과 사용성을 기준으로 결정합니다.

기능은 먼저 로컬 환경에서 테스트하고, 이후 실제 사용 환경에 가까운 운영 테스트를 거쳐 검증할 예정입니다. 카카오톡/문자 공유 주문은 실제 휴대폰 공유 흐름에서 검증하고, 통화녹음 자동 업로드처럼 기기 권한, 네트워크, 백그라운드 실행 정책의 영향을 받는 기능은 후순위 단계에서 실제 휴대폰과 운영 환경으로 반복 검증합니다.

## 향후 방향

앞으로 출고비서는 다음 기능으로 확장될 예정입니다.

- 문자, 카카오톡, 이메일 주문 정보 수집
- 품목, 수량, 거래처, 배송지 자동 추출
- 주문 후보 확인 및 수정
- 출고표 자동 생성
- 반복 거래처와 품목 패턴 학습
- 통화녹음 주문 분석
- 소규모 유통업자를 위한 모바일 중심 업무 자동화
