Upload Strategy

  1. Android asks the API server to create an upload session.
  2. The API server validates auth, consent, file size, and content type.
  3. The API server returns a MinIO presigned PUT URL.
  4. Android uploads the audio file directly to MinIO.
  5. Android calls the API server complete endpoint.
  6. The API server verifies the object and registers an analysis job.
