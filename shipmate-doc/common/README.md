# ShipMate Common Docs

All shared or common design documentation belongs under this folder.

```text
shipmate-doc/common/
  yaml/   source documents
  html/   browser-viewable documents
```

Use this folder for project-wide design decisions such as:

- product overview
- project structure
- shared architecture
- documentation guidelines
- common status models
- cross-project API decisions

Do not store Android-only documentation in `shipmate-doc/common/`.
Do not store shipmate-admin-only documentation in `shipmate-doc/common/`.
