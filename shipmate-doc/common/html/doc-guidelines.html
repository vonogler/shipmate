ShipMate Documentation Guidelines

Common design documentation belongs under shipmate-doc/common/. YAML is the source of truth.

Required Domain Folders

  • Common design documentation: shipmate-doc/common/
  • Android documentation: shipmate-doc/android/
  • shipmate-admin documentation: shipmate-doc/admin/
  • Field names, master codes, and error code numbers: shipmate-common/data/yaml/

Shared Asset Source

  • shipmate-common/data/yaml/field-names.yaml
  • shipmate-common/data/yaml/master-codes.yaml is the future source for RDB master code tables and seed data.
  • shipmate-common/data/yaml/error-codes.yaml

Common Structure

  • common/yaml/ stores common design source documents.
  • common/html/ stores common design browser-viewable documents.
  • Examples: project structure, product overview, shared architecture, documentation guidelines.

Android Structure

  • android/yaml/ stores Android source documents.
  • android/html/ stores Android browser-viewable documents.

Admin Structure

  • admin/yaml/ stores shipmate-admin source documents.
  • admin/html/ stores shipmate-admin browser-viewable documents.
