# ShipMate 관리자 문서

`shipmate-admin` 프로젝트에 대한 모든 문서는 이 폴더에 둡니다.

`shipmate-admin`은 출고비서 운영자와 사원이 접속하는 내부관리자입니다. 현재 범위는 내부 계정 로그인, 운영 대시보드, 이용자/가맹점 관리, 직원 계정 생성, 주문 원문/출고표 초안/제출 출고표 조회, 통화 녹음 관리, 오류 로그, 변경 이력, 백업 미리보기, 시스템 설정 조회입니다.

```text
shipmate-doc/shipmate-admin/
  *.md    원본 문서
  html/   브라우저에서 볼 수 있는 문서
```

`shipmate-admin` 문서를 `shipmate-doc/shipmate-android/`에 보관하지 않습니다.
Android 전용 문서를 `shipmate-doc/shipmate-admin/`에 보관하지 않습니다.
