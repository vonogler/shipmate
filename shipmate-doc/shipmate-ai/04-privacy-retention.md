# 04. 개인정보와 보관 정책

## 목적

통화녹음에는 개인정보와 업무상 민감한 내용이 포함될 수 있다. AI 학습 목적의 사용은 일반 서비스 처리 목적과 분리해야 한다.

## 동의 분리

동의 상태는 다음처럼 분리한다.

1. 서비스 처리 동의: 업로드, STT, 출고표 초안 생성.
2. AI 학습 동의: 검수된 음성/전사문/출고표 데이터를 모델 개선에 사용.

## 권장 보관 기간

| 데이터 | 권장 보관 기간 | 비고 |
|---|---:|---|
| 원본 통화 음성 | 30~90일 | 전사문 검수와 재처리용 |
| 학습 목적 원본 통화 음성 | 최대 1년 권장 | 별도 학습 동의 필요 |
| 원본 전사문 | 1년 | 검수 후 단축 가능 |
| 수정 전사문 | 1~3년 | 장기 보관 전 마스킹 권장 |
| 출고표 수정 데이터 | 3년 | 업무 추적 가치 보존 |
| 비식별 학습 sample | 장기 보관 가능 | 재식별 위험 통제 필요 |

## 데이터 보호 요구사항

- 음성은 접근 제한이 적용된 object storage에 보관한다.
- 저장 구간과 전송 구간을 암호화한다.
- 음성 및 전사문 접근 이력을 기록한다.
- 삭제 요청 처리 흐름을 지원한다.
- 학습 가능 데이터와 일반 서비스 데이터를 분리한다.
- 전화번호, 주소, 이름, 계좌처럼 보이는 문자열은 가능한 범위에서 마스킹한다.

## 삭제 정책

동의가 철회되거나 보관 기간이 만료되면 다음을 수행한다.

- 법령상 보관 의무가 없으면 원본 음성을 삭제한다.
- 향후 학습 export에서 해당 sample을 제외한다.
- 법적으로 필요한 추적 record만 남긴다.
- 이미 학습 데이터로 export된 경우 영향을 받는 데이터셋 version을 검토 대상으로 표시한다.

## 운영 원칙

명시적으로 학습 가능 상태가 아닌 데이터는 학습에 사용하지 않는다.
