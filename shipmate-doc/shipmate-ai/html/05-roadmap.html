05. 로드맵

1단계: 기준 운영 흐름 구축

  • Clova Speech로 STT를 처리한다.
  • 외부 LLM으로 출고표 초안 JSON을 생성한다.
  • Admin에 전사문과 출고표 초안 검수 기능을 추가한다.
  • 검수된 전사문과 검수된 출고표 초안을 저장한다.

2단계: 데이터 품질과 평가 체계 구축

  • ASR 평가셋을 정의한다.
  • 출고정보 추출 평가셋을 정의한다.
  • WER, CER, 도메인 용어 정확도, 출고표 필드 정확도를 추적한다.
  • 수정 사유 code를 추가한다.

3단계: Prompt와 검증 최적화

  • prompt를 개선한다.
  • 엄격한 JSON schema 검증을 추가한다.
  • 고객/상품 후보 ranking을 추가한다.
  • 누락 필드와 warning 생성을 추가한다.

4단계: 모델 파인튜닝 테스트

  • 검수된 음성/전사문 pair로 ASR 모델을 파인튜닝한다.
  • 검수된 출고표 JSON pair로 LLM 또는 adapter 모델을 파인튜닝한다.
  • Clova Speech와 외부 LLM 기준 성능과 비교한다.

5단계: Private AI 운영 검토

  • 로컬 ASR 또는 LLM 모델 운영 여부를 결정한다.
  • model registry를 추가한다.
  • 배포 승인 workflow를 추가한다.
  • rollback과 version별 평가 보고서를 추가한다.
