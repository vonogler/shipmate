프로젝트 경계

shipmate-api는 업로드 API, 업무 데이터 API, 운영 상태 업데이트를 담당한다.

shipmate-ai는 AI worker, 실험, 데이터셋, 모델 평가, 모델 산출물을 담당한다.

shipmate-admin은 사람 검수 화면과 최종 승인 흐름을 담당한다.

shipmate-doc은 아키텍처와 정책 문서를 담당한다.
