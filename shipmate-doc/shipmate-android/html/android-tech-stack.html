항목값

선정 이유:

  • Android 8.0 이상이면 소상공인 사용자를 위한 실사용 단말 범위를 충분히 넓게 유지할 수 있다.
  • API 36은 현재 앱에서 선택한 Android SDK target이다.
  • 로컬 SDK 사용 가능 여부를 확인한 뒤 compile/target SDK를 상향할 수 있다.

업로드 전략

기본 전략은 MinIO Presigned URL 직접 업로드이다.

처리 흐름:

  1. 1. Android가 API 서버에 업로드 세션 생성을 요청한다.
  2. 2. API 서버가 사용자 인증, 업로드 동의, 파일 크기, content type을 검증한다.
  3. 3. API 서버가 metadata를 생성하고 MinIO presigned PUT URL을 반환한다.
  4. 4. Android가 음성 파일을 MinIO로 직접 업로드한다.
  5. 5. Android가 API 서버의 업로드 완료 endpoint를 호출한다.
  6. 6. API 서버가 MinIO object를 검증하고 분석 job을 등록한다.

향후 확장:

  • 대용량 파일용 S3-compatible multipart upload.
  • 모바일 네트워크 불안정성 대응을 위한 WorkManager retry.
