WSL Android SDK 빌드 검증

Windows Android Studio 설치본이 없거나 경로가 다른 개발 PC에서도 shipmate-android를 WSL에서 검증할 수 있게 한다.

기본 원칙

  • Android SDK는 저장소에 커밋하지 않는다.
  • 검증용 SDK는 .codex-tmp/android-sdk 아래에 둔다.
  • local.properties는 로컬 전용 파일로 유지한다.
  • Windows SDK 경로가 없어도 ANDROID_HOME, ANDROID_SDK_ROOT 환경변수로 빌드할 수 있다.

빌드 명령

cd shipmate-android
JAVA_HOME=/usr/lib/jvm/java-17-openjdk \
GRADLE_USER_HOME="$PWD/../.codex-tmp/android-gradle-home" \
ANDROID_HOME="$PWD/../.codex-tmp/android-sdk" \
ANDROID_SDK_ROOT="$PWD/../.codex-tmp/android-sdk" \
./gradlew assembleDebug \
  -Dorg.gradle.java.home=/usr/lib/jvm/java-17-openjdk \
  --no-daemon --console=plain

오류 처리

증상처리
SDK location not foundANDROID_HOME, ANDROID_SDK_ROOT가 .codex-tmp/android-sdk를 가리키는지 확인한다.
Gradle lock이 read-only home에 생김GRADLE_USER_HOME을 .codex-tmp/android-gradle-home으로 지정한다.
샌드박스에서 Operation not permitted외부 실행 권한으로 같은 빌드 명령을 재실행한다.

검증 기록

2026-06-24 기준 WSL .codex-tmp/android-sdk 구성 후 assembleDebug가 통과했다.
