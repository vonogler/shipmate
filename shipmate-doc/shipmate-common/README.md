# ShipMate 공통 문서

공유 설계 문서와 프로젝트 전반의 운영 기준은 이 폴더에 둡니다.

```text
shipmate-doc/shipmate-common/
  *.md    원본 문서
  html/   브라우저에서 볼 수 있는 문서
```

이 폴더에 두는 문서 예시:

- 개발 진행사항
- 문서 작성 가이드라인
- 제품 개요
- 프로젝트 구조
- 공통 아키텍처
- 공통 상태 모델
- 프로젝트 간 API 결정사항

Android 전용 문서는 `shipmate-doc/shipmate-common/`에 보관하지 않습니다.
`shipmate-admin` 전용 문서는 `shipmate-doc/shipmate-common/`에 보관하지 않습니다.
