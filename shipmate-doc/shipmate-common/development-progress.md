# 개발 진행사항

## 현재 기준

- 날짜: 2026-06-21
- 세션 ID: 019e8c27-42d5-7790-8c52-4dfabe7cb8f6
- 전체 단계: 주문 입력 채널 MVP와 가맹점 검수 화면 기반을 확장하고, 내부관리자 1차 필수 기능을 구현한 상태
- 주문 채널 개발 우선순위: 카카오톡, 문자, 이메일, 전용 주문 페이지, 기타 채널 순서로 진행한다.
- 전화 및 통화녹음 기능: 더 이상 신규 개발 대상으로 진행하지 않는다. 사용자가 직접 전화 또는 통화녹음 기능 개발을 명시적으로 요청한 경우에만 해당 영역을 검토하거나 수정한다.
- 문서 원칙: Markdown 원본과 HTML 보기 파일을 함께 관리한다.
- 기본 언어: 문서와 사용자 화면 문구는 한국어를 기본으로 한다.
- DB 기준: 로컬 운영 유사 환경은 Docker Compose + MySQL 8.4로 검증하며, 개발 계정/비밀번호/스키마는 임시로 모두 `shipmate`를 사용한다.
- 테이블 명명: 모든 업무 테이블명은 `tb_` prefix를 붙이고, 공통 마스터 코드 테이블은 `tb_code`로 단일화한다.
