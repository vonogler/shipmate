# 공통 오류 코드

## 문서 정보

| 항목 | 값 |
|---|---|
| 저장소 | `shipmate-common` |
| 담당 | common |
| 갱신일 | 2026-06-12 |
| 기준 형식 | Markdown 원본과 HTML 보기 파일 |

## 번호 체계

오류 코드는 `SM-{domain}-{number}` 형식을 사용한다.

| Domain | 범위 |
|---|---|
| common | `SM-COM-0001`부터 `SM-COM-0999`까지 |
| auth | `SM-AUTH-1000`부터 `SM-AUTH-1999`까지 |
| upload | `SM-UPL-2000`부터 `SM-UPL-2999`까지 |
| analysis | `SM-ANL-3000`부터 `SM-ANL-3999`까지 |
| order draft | `SM-ODF-5000`부터 `SM-ODF-5999`까지 |
| email | `SM-EML-7000`부터 `SM-EML-7999`까지 |
| Gmail | `SM-GML-9000`부터 `SM-GML-9999`까지 |

## 오류 목록

| Code | HTTP status | 메시지 | Client action |
|---|---|---|---|
| `SM-COM-0001` | 400 | 잘못된 요청입니다. | 요청 field를 확인한 뒤 다시 시도한다. |
| `SM-COM-0002` | 500 | 예상하지 못한 서버 오류입니다. | 잠시 뒤 다시 시도하거나 지원 담당자에게 문의한다. |
| `SM-UPL-2001` | 400 | 업로드 동의가 필요합니다. | 업로드 전에 사용자 동의를 요청한다. |
| `SM-UPL-2002` | 400 | 지원하지 않는 오디오 content type입니다. | 지원되는 오디오 파일을 선택하도록 안내한다. |
| `SM-UPL-2003` | 413 | 오디오 파일이 너무 큽니다. | 더 작은 파일을 선택하도록 안내한다. |
| `SM-UPL-2004` | 410 | 업로드 URL이 만료되었습니다. | 새 업로드 session을 만들고 다시 시도한다. |
| `SM-UPL-2005` | 502 | Object storage 업로드 검증에 실패했습니다. | 업로드를 다시 시도하거나 지원 담당자에게 문의한다. |
| `SM-UPL-2006` | 404 | 녹음 파일을 찾을 수 없습니다. | 업로드 목록을 새로고침한 뒤 다시 시도한다. |
| `SM-UPL-2007` | 502 | 업로드 URL을 만들 수 없습니다. | 업로드 session 생성을 다시 시도한다. |
| `SM-ANL-3001` | 500 | 오디오 분석에 실패했습니다. | 분석을 다시 시도할 수 있도록 안내한다. |
| `SM-EML-7101` | 404 | 이메일 수집 설정이 없습니다. | 이메일 수집 설정을 먼저 저장한다. |
| `SM-EML-7102` | 502 | 이메일 메일함 연결 확인에 실패했습니다. | 서버, 계정, 앱 비밀번호, IMAP 사용 여부를 확인한다. |
| `SM-EML-7201` | 404 | 이메일 첨부파일을 찾을 수 없습니다. | 첨부 목록을 새로고침한 뒤 다시 시도한다. |
| `SM-EML-7202` | 403 | 이메일 첨부파일에 접근할 권한이 없습니다. | 현재 이용자 계정으로 다시 로그인한다. |
| `SM-EML-7203` | 502 | 이메일 첨부파일 다운로드 URL을 생성하지 못했습니다. | 객체 저장소 상태를 확인한 뒤 다시 시도한다. |
| `SM-EML-7204` | 502 | IMAP 첨부 원본을 저장하지 못했습니다. | 첨부 저장 실패 이력을 확인하고 필요 시 메일을 다시 수집한다. |
| `SM-GML-9101` | 502 | Gmail polling 실행에 실패했습니다. | Google OAuth 연결과 Gmail API 상태를 확인한다. |
| `SM-GML-9102` | 404 | Google OAuth 연결 토큰이 없습니다. | Google Gmail 연결을 먼저 완료한다. |

| `SM-GML-9104` | 502 | Gmail 또는 Google OAuth API 호출이 실패했습니다. | Google API 응답 상태와 권한 scope를 확인한다. |
| `SM-GML-9105` | 502 | Gmail 또는 Google OAuth API 통신에 실패했습니다. | 네트워크와 Google API 상태를 확인한다. |
| `SM-GML-9106` | 500 | Gmail 수집 원문에서 출고표 초안을 자동 생성하지 못했습니다. | 원문은 보존되므로 초안 생성 로그를 확인한다. |
| `SM-GML-9107` | 502 | Gmail 첨부 원본을 저장하지 못했습니다. | 객체 저장소 상태와 첨부 크기를 확인한다. |
| `SM-GML-9108` | 502 | Gmail 메시지 읽음 처리에 실패했습니다. | OAuth scope가 `gmail.modify`인지 확인하고 필요 시 다시 연결한다. |
| `SM-ODF-5005` | 400 | 검수 필요 초안은 검수 내용을 저장한 뒤 제출할 수 있습니다. | 초안 검수 내용을 저장한 뒤 다시 제출한다. |
| `SM-ODF-5006` | 400 | 출고표 제출 전 필수값을 확인하세요. | 수취인, 연락처, 주소, 품목명, 수량, 단위를 보완한 뒤 다시 제출한다. |
| `SM-ODF-5007` | 400 | 제출된 출고표만 재검수로 전환할 수 있습니다. | 제출 상태의 출고표를 선택한 뒤 재검수 전환을 다시 실행한다. |
