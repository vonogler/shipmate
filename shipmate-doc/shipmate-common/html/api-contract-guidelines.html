API 계약 지침

shipmate-api, Android, Merchant, Admin 사이의 API 계약을 통일한다.

기본 원칙

  • API field는 필드 딕셔너리를 따른다.
  • DB column은 DB 컬럼 딕셔너리를 따른다.
  • userId, phone, status, type 단독 field를 사용하지 않는다.

경로 규칙

/api/inbound-messages
/api/order-drafts
/api/business-documents
/api/customers
/api/items

주문 원문 생성 예

POST /api/inbound-messages
{
  "merchantId": "merchant_001",
  "merchantStaffId": "staff_001",
  "sourceChannel": "KAKAO_PASTE",
  "businessChannel": "PACKAGING_CUSTOM",
  "rawText": "지난번 쇼핑백 1,000장 다시 주세요."
}
