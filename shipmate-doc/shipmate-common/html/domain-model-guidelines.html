도메인 모델 지침

카카오톡, 문자, 이메일, 주문 페이지에서 들어온 주문 원문을 주문 초안, 검수, 업무문서로 연결하는 공통 도메인 모델을 정의한다.

핵심 원칙

  • sourceChannel과 businessChannel을 분리한다.
  • AI 결과는 확정 주문이 아니라 검수 가능한 후보로 저장한다.
  • 출고표만 전제로 하지 않고 작업지시서, 견적요청서, 납품서, 택배 CSV까지 확장 가능하게 둔다.

주요 엔티티

엔티티역할
InboundMessage카카오톡/문자/이메일/주문 페이지에서 들어온 주문 원문
OrderDraft원문에서 만든 주문 또는 견적 후보
OrderDraftLineItem주문 초안의 품목/수량/옵션 후보
BusinessDocument작업지시서, 출고표, 납품서, 택배 CSV 같은 업무 산출물의 공통 부모
Customer출고비서 이용자에게 주문하는 거래처

기본 관계

InboundMessage 1 -> N OrderDraft
OrderDraft 1 -> N OrderDraftLineItem
OrderDraft 1 -> N ReviewResult
OrderDraft 1 -> N BusinessDocument

MVP 모델 범위

1차 구현에는 InboundMessage, OrderDraft, OrderDraftLineItem, BusinessDocument, Customer를 필수로 둔다.
