공통 마스터 코드

공유 마스터 코드는 문서 자산으로 관리한다. RDB seed data와 master code table은 이 문서를 기준으로 만든다.

업무 테이블보다 tb_code를 먼저 생성한다. 코드 그룹 설명은 code='__GROUP__' row로 관리한다.

현재 코드 그룹

code_group설명
SOURCE_CHANNEL주문 원문 입력 경로
BUSINESS_CHANNEL출고비서 이용자의 업종/업무 채널
SHIPPING_CARRIER택배 CSV 출력 대상
ITEM_UNIT품목 수량 단위
INBOUND_MESSAGE_STATUS주문 원문 처리 상태
ORDER_DRAFT_STATUS출고표 초안 상태
MERCHANT_USER_ROLE이용자 계정 권한
CALL_RECORDING_STATUS통화녹음 업로드와 분석 상태
CONSENT_TYPE사용자 동의 유형

주요 코드값

code_groupcode
SOURCE_CHANNELKAKAO_PASTE, SMS_SHARE, EMAIL, ORDER_PAGE
BUSINESS_CHANNELPACKAGING_CUSTOM, BEAUTY_SUPPLIES, MRO_SUPPLIES, APPAREL_WHOLESALE, METAL_MATERIALS, PHARMACY_SUPPLIES

MERCHANT_USER_ROLEADMIN, OPERATOR, VIEWER
