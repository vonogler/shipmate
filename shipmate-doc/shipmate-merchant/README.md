# ShipMate Merchant 문서

`shipmate-merchant` 프로젝트 문서는 이 폴더에 둡니다.

`shipmate-merchant`는 출고비서 이용자, 즉 가맹점과 업체가 사용하는 플랫폼입니다.

```text
shipmate-doc/shipmate-merchant/
  *.md    원본 문서
  html/   브라우저에서 볼 수 있는 문서
```

이 폴더에 두는 문서 예시:

- 이용자별 브랜드 주문 채널
- 문자 공유 기반 출고표 생성
- 주문 처리 기능 로드맵
- 포장재/판촉물/맞춤 제작 소모품 채널
- 주문 링크 관리
- 고객 공개 주문 페이지 설정
- 가맹점 주문 검수 흐름
- 가맹점 프로필과 브랜드 설정
- 타깃 업종 우선순위

출고비서 내부 운영자용 문서는 `shipmate-doc/shipmate-admin/`에 둡니다.
Android 앱 문서는 `shipmate-doc/shipmate-android/`에 둡니다.
여러 프로젝트에 걸친 공통 정책은 `shipmate-doc/shipmate-common/`에 둡니다.
