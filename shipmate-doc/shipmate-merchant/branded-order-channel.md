# 이용자별 브랜드 주문 채널 전략

## 문제 인식

`stackcube`처럼 플랫폼 공통 채널 링크를 고객에게 전달하면 고객은 자신이 거래하는 업체가 아니라 제3의 플랫폼에 주문하는 것처럼 느낄 수 있다.

예를 들어 `(주)한국유통`의 고객이 `stackcube` 채널 링크를 받으면 다음과 같은 혼란이 생길 수 있다.

```text
내가 거래하는 한국유통에 주문하는 건가?
아니면 스택큐브라는 다른 서비스에 주문하는 건가?
```

B2B 발주에서는 고객 신뢰와 익숙함이 중요하다. 따라서 고객이 거래처 자체 채널에 주문하는 느낌을 주는 구조가 더 적합하다.

## 권장 방향

출고비서는 이용자별 주문 채널을 제공한다.

```text
출고비서 이용자: (주)한국유통
고객에게 보이는 채널: (주)한국유통 주문채널
실제 처리 시스템: 출고비서
```

고객은 `(주)한국유통`에 주문한다고 느끼고, 출고비서는 내부에서 주문 수집, 분석, 출고표 초안 생성을 담당한다.

## 기본 흐름

```text
(주)한국유통이 출고비서 가입
-> 출고비서에서 한국유통 전용 주문 채널 생성
-> 한국유통이 고객에게 해당 링크 전달
-> 고객은 한국유통 채널에 주문한다고 느낌
-> 출고비서가 주문을 수집/분석/정리
-> 한국유통 관리자 화면에서 검수/출고 처리
```

## 구현 방식

### 1단계: 출고비서 자체 웹 주문 채널

가장 현실적인 MVP 방식이다.

```text
https://order.shipmate.co.kr/korea-distribution
https://order.shipmate.co.kr/c/한국유통
```

고객 화면에서는 `출고비서`보다 거래처 브랜드를 먼저 보여준다.

```text
(주)한국유통 주문 접수
품목 / 수량 / 요청일 / 메모 입력
카카오톡으로 문의하기
이메일로 발주서 첨부
```

장점:

- 바로 만들 수 있다.
- 고객별 링크를 제공할 수 있다.
- 브랜드명, 로고, 전화번호, 주소를 커스터마이징할 수 있다.
- 이메일, 카카오톡, 웹 주문을 한 화면으로 묶기 쉽다.

### 2단계: 이용자 보유 카카오톡 채널 연결

이용자가 이미 가지고 있는 카카오톡 채널을 출고비서에 연결하게 한다.

```text
(주)한국유통 카카오톡 채널
-> 고객 주문 메시지
-> 출고비서가 메시지 수집/분석
-> 관리자 검수
```

장점:

- 고객이 가장 자연스럽게 느낀다.
- 고객은 한국유통에 주문한다고 인식한다.

주의사항:

- 카카오 채널 API, 챗봇, 상담톡 정책과 권한 확인이 필요하다.
- 이용자마다 채널 개설 또는 연동 절차가 필요하다.
- MVP로는 웹 링크보다 복잡하다.

### 3단계: 출고비서 채널 개설 대행

출고비서가 `(주)한국유통` 카카오톡 채널을 만들어 주는 모델도 가능하다.

다만 운영 부담이 크므로 초기 MVP에는 적합하지 않다.

확인할 사항:

- 채널 소유권을 누구에게 둘지 정해야 한다.
- 사업자 인증을 누가 할지 정해야 한다.
- 카카오 정책상 대행 생성과 운영이 가능한지 확인해야 한다.
- 해지 시 채널 이전 또는 폐쇄 정책이 필요하다.
- 고객 개인정보와 상담 이력 소유권을 명확히 해야 한다.

## 추천 단계

```text
1단계: 출고비서 자체 웹 주문 채널 제공
2단계: 이용자별 브랜드 페이지 제공
3단계: 이용자가 가진 카카오톡 채널 링크/버튼 연결
4단계: 카카오톡 채널 API 연동
5단계: 필요 시 채널 개설 대행 검토
```

## MVP 제안

MVP에서는 이용자별 주문 링크를 먼저 제공한다.

```text
order.shipmate.co.kr/한국유통
```

고객 화면 브랜딩:

```text
(주)한국유통 주문 접수
```

내부 처리:

```text
출고비서가 주문 수집
-> 주문 내용 분석
-> 출고표 초안 생성
-> 관리자 검수
```

## 결론

고객 경험 기준으로는 플랫폼 공통 채널로 유도하는 방식보다 이용자별 자체 주문 채널처럼 보이게 하는 방식이 더 좋다.

출고비서 MVP는 자체 웹 주문 채널을 먼저 제공하고, 이후 카카오톡 채널 연결과 API 연동으로 확장한다.
