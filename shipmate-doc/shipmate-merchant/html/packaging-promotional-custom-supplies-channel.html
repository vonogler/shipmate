포장재/판촉물/맞춤 제작 소모품 채널

목적

출고비서의 초기 영업과 제품 뼈대를 포장재/판촉물/맞춤 제작 소모품 채널로 따로 기록한다.

결론은 외부 영업과 초기 화면은 한 가지 업종에 집중하고, 내부 데이터 구조는 세 가지 업종을 확장 가능하게 둔다.

영업/화면/샘플: 포장재 주문제작에 집중
데이터 모델/문서 타입: 포장재, 판촉물, 맞춤 제작 소모품을 확장 가능하게 설계

집중 타깃

초기 집중 타깃은 포장재 주문제작이다.

  • 박스
  • 쇼핑백
  • 스티커
  • 라벨
  • 포장용 봉투
  • 소량 패키지 제작
카톡으로 받은 포장재 주문을
견적 후보, 작업지시서, 출고표로 정리합니다.

왜 한 가지에 집중하는가

포장재, 판촉물, 맞춤 제작 소모품은 비슷하지만 영업 메시지가 다르다.

구분고객이 기대하는 핵심
포장재박스, 쇼핑백, 라벨, 스티커, 포장 사양, 인쇄 파일
판촉물행사명, 로고, 인쇄 위치, 납기, 수량, 품목 옵션
맞춤 제작 소모품규격, 재질, 반복 주문, 작업 조건

처음부터 “세 가지를 모두 지원한다”고 말하면 메시지가 흐려진다. 반대로 “포장재 카톡 주문을 작업지시서와 출고표로 정리한다”고 말하면 고객이 바로 이해하기 쉽다.

왜 포장재 주문제작인가

  • 참고 모델이 명확하다.
  • 박스, 쇼핑백, 스티커, 라벨까지 확장 가능하다.
  • “지난번 주문”, “로고 변경”, “수량 변경”, “디자인 파일 검수” 같은 출고비서 핵심 기능이 잘 드러난다.
  • 판촉물보다 상품 범위가 덜 넓다.
  • 금속/의약품보다 규제와 견적 난이도가 낮다.

참고 사이트: 패커티브, 레드프린팅

공통 업무 흐름

카카오톡/문자/이메일 주문 원문
-> 주문 또는 견적 후보 추출
-> 이용자 검수
-> 작업지시서 생성
-> 출고표/납품서/택배 CSV 생성

프로젝트 구성 결정

현재 단계에서는 업종별 프로젝트를 새로 만들지 않고 shipmate-merchant 안에서 업종 템플릿으로 나눈다.

    약국 소모품

핵심 흐름은 업종별로 완전히 다르지 않다. 주문 원문 수집, AI 후보 추출, 이용자 검수, 업무문서 생성, 택배 CSV/납품서 출력은 공통이며, 업종별 차이는 주로 추출 필드, 검수 화면 템플릿, 문서 템플릿이다.

시장 검증 전 프로젝트를 나누면 로그인, 권한, 거래처, 주문 초안, 검수 화면을 중복 구현하게 된다. 초기 구현은 PACKAGING_CUSTOM만 실제 화면까지 만들고, 다른 업종은 businessChannel 구조에서 확장 가능하게만 둔다.

프로젝트 분리는 업종별 로그인/권한, 요금제, 화면 흐름, 운영팀, 배포 주기, 법적/규제 요건, 별도 브랜드 판매 필요성이 독립적으로 커졌을 때 검토한다.

개발 순서

  1. shipmate-api에 주문 원문과 주문 초안의 공통 저장 구조를 만든다.
  2. sourceChannel과 businessChannel을 분리해 저장한다.
  3. 첫 businessChannel은 PACKAGING_CUSTOM으로 둔다.
  4. shipmate-merchant에 주문 원문 목록과 주문 초안 목록을 만든다.
  5. 포장재 주문제작 기준 검수 화면을 만든다.
  6. AI 없이도 원문을 수동으로 주문/견적 후보로 저장할 수 있게 한다.
  7. AI 주문 후보 추출을 붙인다.
  8. 작업지시서 초안을 만든다.
  9. 출고표/납품서 초안을 만든다.
  10. 승인 주문 기준 택배 CSV 다운로드를 만든다.
  11. 지난 주문 참조와 반복 주문 불러오기를 붙인다.
  12. 이후 PROMOTIONAL_GOODS, CUSTOM_SUPPLIES 필드를 확장한다.

확장 필드

판촉물 확장 필드: 행사명, 로고 인쇄 위치, 인쇄 색상, 개별 포장 여부, 증정/납품 장소, 행사일.

맞춤 제작 소모품 확장 필드: 규격, 재질, 가공 조건, 반복 주문 여부, 샘플 필요 여부, 작업 조건.

만들지 않을 것

  • 세 업종 전체를 한 화면에서 모두 설명하는 범용 랜딩
  • 자동 카카오톡 수집
  • 복잡한 ERP 연동
  • 완전 자동 승인
  • 금속 견적 자동화
  • 전문의약품 기능

결론

초기 제품과 영업은 포장재 주문제작에 집중한다.

다만 내부 모델은 포장재/판촉물/맞춤 제작 소모품 채널로 묶어, 나중에 판촉물과 맞춤 제작 소모품으로 자연스럽게 확장할 수 있게 설계한다.
